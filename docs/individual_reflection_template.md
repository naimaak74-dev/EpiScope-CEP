# Individual Reflection Template (each member writes their own half-page)

Write in your own words:
1. What work did I personally implement and verify?
2. What technical decision was most difficult, and what alternatives did I consider?
3. What did I learn about data quality, scalability, privacy, or model uncertainty?
4. What failed or changed during testing, and how did I respond?
5. What would I improve before real-world use?

Do not submit this template unchanged. Each member must write an authentic reflection.
